## 정의

사용자가 자연어로 질문을 입력하면, AI가 이를 해석해 자동으로 데이터 쿼리·시각화·해설을 제공하는 분석 방식입니다.

즉, 시각화 전문 도구나 컴퓨터 언어를 사용하지 않고 데이터 시각화를 하는 것을 말합니다.

> ℹ️대화형 AI 시각화 도구도 시각화 도구이므로 시각화 도구를 사용하지 않는다는 것은 좀 이상한 표현입니다. 전통적인 시각화 도구가 아닌 자연어를 명령어로 입력받는 시각화 도구를 사용하는 방법론입니다.

## **구성 요소**

- 자연어 인터페이스(NLI) → 질의를 구조화된 쿼리(SQL/파이썬 등)로 변환
- 대형 언어 모델(LLM) 기반 엔진 → 컨텍스트 인식·추론 수행
- 시각화 모듈 → 차트·그래프 생성 및 요약 내러티브 제공

자연어로 데이터 시각화를 할 수 있어야 합니다.

## **주요 장점**

- 비전문가도 데이터 분석 가능
- 반복 대화로 점진적 심화 분석
- 시각화와 해설을 한 번에 제공해 의사결정 지원

시각화 도구는 사용법을 따로 익혀야 하기 때문에 비전문가는 하기 어렵지만 자연어로 시각화할 수 있다면 비전문가도 할 수 있습니다.

## **대표 사례**

- Microsoft Power BI Q&A
- Tableau Ask Data
- OpenAI ChatGPT Advanced Data Analysis

### **주의할 점**

데이터 정확성과 보안 관리 필요하고 복잡한 모델링·대용량 처리엔 한계가 있을 수 있습니다.

복잡한 시각화를 하지 못하고 의도한 대로 시각화하지 못합니다. 이런 경우 바이브 코딩과 데이터 시각화가 결합한 바이브 데이터 시각화를 하는 것이 더 나은 선택입니ㅏㄷ.
